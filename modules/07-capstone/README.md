# Module 07: Commerce Portal Capstone

Build a maintainable end-to-end suite combining login, order filtering, files, API mocking, artifacts, and browser coverage.

The capstone is assessed by behavior and explanation. A passing test that uses a brittle selector or shared state is incomplete. Each test should establish its own state, perform one coherent user behavior, and verify an observable result. The learner README must explain why each locator and fixture was chosen.

Read Objectives, Concepts, Exercises, then Verification in order.
